# Караоке на заказ — лендинг Евгения

Статический сайт на русском языке: HTML и CSS, без сборки, JavaScript, сторонних шрифтов и аналитики. Контакт: https://t.me/ilnitskiii.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** в этом репозитории.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/ (root)**, затем **Save**.
4. После успешной публикации сайт будет доступен по адресу https://ilnitskii.github.io/karaoke-landing/.

Pages пока не включён: владелец публикует сайт самостоятельно. Инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site.

## Файлы

- `index.html` — весь текст, ссылки, примеры, цены и контакт.
- `styles.css` — оформление и адаптация под телефон.
- `assets/favicon.svg` — значок сайта.
- `.nojekyll` — статическая выдача без обработки Jekyll.

Все локальные пути относительные: сайт работает и в подпапке GitHub Pages. Для локального просмотра можно открыть `index.html` в браузере либо запустить любой статический HTTP-сервер из этой папки.

## Редактирование

Контакт Telegram указан в четырёх ссылках в `index.html`. При изменении цен обновляйте итоговые суммы и стоимость одной песни в таблице. Ссылки на примеры ведут на Яндекс Диск и открываются в новой вкладке. Видеофайлы в репозиторий не включены.

Условия: 400 ₽ за песню; пакеты 5 / 1 850 ₽, 10 / 3 500 ₽, 20 / 6 400 ₽, 50 / 14 500 ₽. Срок, оплата и технические параметры обсуждаются до заказа. Бесплатная первая песня в публичное предложение не включена.

## Дизайн и доступность

Светлая бумажная основа, тёмный текст, красный акцент и графическая пластинка, нарисованная CSS. Иллюстрация декоративная, не изображает интерфейс готового караоке. Семантические разделы, настоящая таблица цен, доступная клавиатурная навигация, видимый фокус, ссылка пропуска навигации и поддержка уменьшенного движения. Вопросы раскрываются нативным элементом `details`; сайт полностью работает без JavaScript.
